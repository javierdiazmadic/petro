RESUMEN EJECUTIVO
═════════════════════════════════════════════════════════════════════════

Se ha implementado un sistema completo y automático de descarga y carga
de modelos de machine learning entrenados cada noche desde GitHub hacia
la aplicación PETRO.

🎯 CADA NOCHE A LAS 3:00 AM UTC:
   1. Entrena 3 modelos (XGBoost, LightGBM, RandomForest)
   2. Exporta en formato .h5 + JSON metadata
   3. Sube a GitHub
   4. Automáticamente descarga desde GitHub
   5. Carga modelos en memoria (ModelsRegistry)
   6. Dashboard obtiene datos frescos
   7. API endpoints listos con /api/v1/models/*

ENDPOINTS API
═════════════════════════════════════════════════════════════════════════

GET /api/v1/models/info
└─ Retorna: Todos los modelos cargados
   - timestamp, best_model, total_models, loaded_models
   - Para cada modelo: name, metrics (R², RMSE, MAE), training_date

GET /api/v1/models/best
└─ Retorna: Mejor modelo (mayor R²)
   - best_model, name, metrics, input_features

GET /api/v1/models/{model_name}
└─ Parámetros: xgboost, lightgbm, randomforest
└─ Retorna: Info completa del modelo

POST /api/v1/models/refresh
└─ Recargar modelos manualmente
