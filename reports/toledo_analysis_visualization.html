🏗️ Arquitectura del Modelo ML

Pipeline de Datos

1. Recolección de Datos

  • Precios históricos: Toledo, Geoportal Ministerio
  • Indicadores externos: Brent, WTI, USD/EUR, CPI España
  • Eventos de noticias: Análisis de impacto geopolítico y económico

2. Ingeniería de Características (56 features)

  • Rezagos: LAG 1-7 para ambos combustibles
  • Promedios móviles: MA 7, 14, 30 días
  • Volatilidad: STD 7, 14, 30 días
  • Momentum: Cambio de 7 días
  • Indicadores técnicos: RSI 14, Spread gasóleo-gasolina
  • Calendario: Día semana, mes, estación, ciclos anuales
  • Noticias: Impacto, sentimiento, categoría
  • Externos: Precios Brent, USD/EUR, CPI esperado

3. Entrenamiento de Modelos

  • XGBoost: 200 árboles, profundidad 6, learning_rate 0.05
  • LightGBM: 200 árboles, num_leaves 31, learning_rate 0.05
  • Ensemble: Promedio ponderado de ambos modelos
  • Validación: Time Series Split (respeta temporalidad)

4. Post-Procesamiento

  • Intervalos de confianza: 80% y 95% basados en errores históricos
  • Probabilidades de aumento/bajada: Distribución empírica
  • Validación de restricciones: Gasóleo A siempre ≥ Gasolina 95

Limitaciones Conocidas

  • Eventos extraordinarios (crisis geopolíticas, pandemias) no son capturados por datos históricos
  • Las predicciones de 30 días usan promedios históricos (deberían usar forecasting recursivo en producción)
  • Los datos de noticias son simulados basados en patrones reales (usar APIs de noticias en producción)
  • Indicadores externos (Brent, USD/EUR) son simulados realistas (usar APIs de mercado financiero)

Mejoras Futuras Recomendadas

  • Datos Reales: Integrar API del Ministerio de Energía para precios en tiempo real
  • Noticias: Usar APIs de noticias (NewsAPI, AlphaVantage) con NLP/Sentiment
  • Indicadores: Obtener Brent, WTI, USD/EUR de APIs de mercados (IEX Cloud, Alpha Vantage)
  • Forecasting Recursivo: Implementar ARIMA o Prophet para predicciones 30+ días
  • Deep Learning: Probar LSTM/GRU con attention para capturar patrones complejos
  • Auto-ML: Usar AutoML (H2O, AutoGluon) para optimización automática
  • Monitoreo: Implementar data drift detection y reentrenamiento automático
